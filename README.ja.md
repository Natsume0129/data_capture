# シナリオ表情データ収集

[English](README.md) | [中文](README.zh-CN.md) | 日本語

## プロジェクトの使い方

先生の例は `question_set/teacher_examples_scenarios_ja.json` にあります。問題セット一覧で **先生の例・表情会話シナリオ（29場面）** を選択してください。
元のPowerPointの題材と中心となる台詞を残し、説明と必要な前置きを補っています。各場面は1〜3句で、PowerPoint内の原画像を使います。
日本語TTS（`ja-JP`）で説明を表示・再生した後、スペースキーで録画と画像・最初の台詞の表示を開始します。その後もスペースキーで順番に進め、最後に終了します。
原画像は `question_set/illustrations/teacher_examples/originals` にあり、同じ場面の全台詞で共通です。

日本の日常を扱う画像セットは `question_set/japan_daily_speech_bubbles.json` です。
各項目には場面、台詞、元の画像プロンプト、実際の生成プロンプト、画像パスが保存されています。
TTSは日本語 `ja-JP` を使用します。概要では短い導入だけを表示します。
スペースキーで吹き出し付きの大きな画像を表示し、反応区間の記録を開始します。反応が終わったら再びスペースキーを押します。
画像は表示前にローカルで読み込みます。従来の練習ルールが適用されるため、この5場面だけを選択した場合、1場面が練習となり、正式クリップは最大4本です。

### 必要な環境

- Windows 10 または 11
- Python 3.13
- FFmpeg：`PATH` に追加するか、アプリ内で実行ファイルを選択
- DirectShow対応カメラ

### インストール

PowerShellを開き、次を実行します。

```powershell
Set-Location "D:\datacapture"
py -3.13 -m venv .venv313
.\.venv313\Scripts\python.exe -m pip install --upgrade pip
.\.venv313\Scripts\python.exe -m pip install -r requirements.txt
```

仮想環境がすでにある場合は、最後の2つのコマンドだけを実行して更新します。

### 起動

```powershell
Set-Location "D:\datacapture"
.\run.ps1
```

PowerShellがローカルスクリプトをブロックする場合：

```powershell
powershell.exe -ExecutionPolicy Bypass -File "D:\datacapture\run.ps1"
```

現在はソースから起動してください。パッケージ化された実行ファイルは、まだ正式な起動方法ではありません。

### 実験の実行

1. 匿名の被験者IDを入力します。
2. 保存先、目標クリップ数、乱数シード、動画分割方法を選択します。
3. `question_set` から1つ以上のCSV問題セットを選択します。
4. カメラを選択し、プレビューで構図と解像度を確認します。
5. 音声を使う場合は、下記の手順でGoogle Cloud TTSを有効にします。
6. 実験を開始します。最初に抽出された場面は練習用で、正式な `manifest.csv` と目標クリップ数には含まれません。
7. 場面の概要を確認します。この段階ではカメラは開いていますが、録画は始まっていません。
8. スペースキーを押して場面を開始します。アプリは場面全体を一本の元動画として連続録画し、同じ場面では常に同じ画像を表示します。
9. 場面内の項目を順番に実行します。
   - 旧形式（`情景,問題,目的,配图`）：内容を読み、または聞いて自然に反応します。表情が自然な状態に戻ったら、スペースキーで次へ進みます。
   - 説明・発話形式（`情景,片段序号,说明,发言,目的,配图`）：最初に説明を表示して再生します。1回目のスペースキーで発話だけを表示・再生し、クリップの開始時刻を記録します。表情反応が終わったらもう一度スペースキーを押し、終了時刻を記録して次の説明へ進みます。
   - 日本語の簡易形式（`場面,セリフ,配图`）：各行が一つの場面と一つの台詞です。`場面`は概要として表示・再生され、スペースキーで録画と`セリフ`の再生を開始し、次のスペースキーでクリップを終了します。
10. 最後の項目が終わると場面の録画を停止します。FFmpegが時刻に基づいて正式クリップを作成します。説明・発話形式の最終クリップには、発話開始から2回目のスペースキーまでの映像だけが含まれます。

選択した保存先には、練習動画、場面の元動画、分割クリップ、`manifest.csv`、`stimuli.json`、`session.json`、時刻ログが作成されます。動画にマイク音声は入りません。ファイルは現在のユーザー権限で作成され、管理者権限なしで削除できます。

TTSを有効にする場合、本文の言語が異なる問題セットを同じ実験で選択しないでください。実験全体で使用できる言語・音声設定は一つだけです。

## Google Cloud TTS APIの設定

アプリはGoogle Cloud Text-to-SpeechのPythonクライアントでLINEAR16 WAVを生成します。音声は実験開始前に生成され、収集中はローカルキャッシュだけを再生します。

1. Google Cloudプロジェクトを作成または選択し、請求先アカウントを関連付け、Cloud Text-to-Speech APIを有効にします。Googleの[セットアップガイド](https://docs.cloud.google.com/text-to-speech/docs/get-started)を参照してください。
2. 有効にしたAPIを呼び出せるサービスアカウントを作成します。Googleの[サービスアカウント作成ガイド](https://docs.cloud.google.com/iam/docs/service-accounts-create)を参照してください。
3. サービスアカウントのJSONキーを作成し、ダウンロードします。現在のアプリはApplication Default Credentialsではなく、このJSONファイルで認証します。Googleの[サービスアカウントキーガイド](https://docs.cloud.google.com/iam/docs/keys-create-delete)を参照してください。
4. JSONはプロジェクトフォルダーと被験者データフォルダーの外に保管します。Gitへコミットしたり、収集データと一緒に共有したりしないでください。
5. アプリで **Google Cloud TTS** を有効にし、**サービスアカウントJSON** からキーを選択します。
6. 選択した問題セットに合わせて **テキスト言語コード** を設定します。
   - 中国語：`cmn-CN`
   - 英語：`en-US`
   - 日本語：`ja-JP`
7. **音声名** は空欄にするとGoogleの既定音声が使われます。言語コードに対応するGoogle Cloudの音声名を指定することもできます。必要に応じて話速を設定します。
8. 実験を開始します。不足している音声はセッション開始前に生成され、`D:\datacapture\tts_cache` に保存されます。新形式では、説明と発話にそれぞれ別のWAVファイルが作成されます。

認証情報ファイルはキャッシュや実験出力へコピーされません。音声生成に失敗した場合、再試行、音声なしで続行、実験をキャンセル、のいずれかを選択できます。
